# Qcam — 無音・高画質 Web カメラ PWA

ブラウザ標準の Web API（`getUserMedia` / `ImageCapture` / WebGL / Web Worker）のみで動作し、ネイティブアプリのインストール不要で使える **無音・高画質 Web カメラ PWA** です。

- **公開 URL（GitHub Pages）**: https://makomo-oss.github.io/Qcam/

## 主な機能

- **完全無音シャッター**: `audio: false` で映像ストリームのみを取得し、音声出力を一切行いません。シャッター押下時は画面の瞬間暗転アニメーションで視覚的に撮影完了を通知します。
- **最大解像度リクエスト**: 起動時に `ideal: 3840×2160`（4K 相当）をリクエストし、センサーが許容する最大解像度でプレビュー・撮影を行います。
- **2つの撮影モード（標準 AVIF `.avif` 出力 / 設定から JPEG 0.95 へ切替可能）**:
  - **標準モード（高速撮影）**: 単一フレーム取得後、WebGL GLSL シェーダーによる輝度アンシャープマスク（輪郭強調）と軽微なコントラスト補正を適用し、端末内 WebAssembly エンコーダ（`libavif` / `libaom`）で高圧縮・高画質な **AVIF（`image/avif`）** として保存。
  - **高画質 HDR モード（暗所・HDR 向け）**: シャッター押下時に 4 フレームを連続取得（約 0.2 秒）し、動き適応型ピクセル平均化で暗所ノイズを低減した上で、WebGL GLSL トーンマッピング（シャドウ持ち上げ＋ハイライト白飛び抑制）を適用して AVIF 出力。
- **カメラ制御・撮影補助 UI**:
  - アウトカメラ（`environment`）/ インカメラ（`user`）切り替え
  - **0.5× 超広角カメラ対応（対応端末）**: iPhone Safari（16.3+ 物理超広角レンズ自動切替）および `zoom < 1.0` または複数背面カメラを公開する Android 端末で `0.5×` ボタン・ピンチ操作・手動レンズ切替に対応
  - タップフォーカス＆露出補正（EV スライダー）
  - ピンチイン・ピンチアウト / スライダー / プリセット倍率によるズーム制御
  - `4:3` / `16:9` アスペクト比切替・`3×3` グリッド表示・セルフタイマー（`3s` / `10s`）
  - 撮影直後のサムネイル表示、拡大プレビュー（`1×` / `2×` / `4×`）、フィルムストリップ確認
- **PWA & 完全クライアント処理**:
  - `manifest.webmanifest` および Service Worker（`sw.js`）により AVIF エンコーダを含めホーム画面追加・オフライン起動に対応。
  - 画像データおよび AVIF エンコードはすべてブラウザメモリ（Web Worker / WebGL / WebAssembly）内のみで処理され、外部サーバーへ一切送信されません。

## OS 別実装方針

| 項目 | Android (Chrome) | iOS (Safari 16.4+) |
|---|---|---|
| 基本撮影方式 | `ImageCapture.takePhoto()` 優先（フォールバック: ストリーム抽出） | `<video>` ストリームから高解像度フレーム抽出 |
| 0.5× 超広角カメラ | `capabilities.zoom.min < 1.0` 対応端末で光学ズーム切替（未公開機種は非表示／手動切替枠を利用） | `enumerateDevices()` により物理「背面超広角カメラ」を自動検出し `0.5×` でレンズ切替 |
| 高画質モード | 連続フレーム取得 ＋ Web Worker / WebGL トーンマッピング | 連続 4 フレーム合成 ＋ Web Worker / WebGL トーンマッピング |
| フォーマット変換 | クライアント内 WebAssembly AVIF エンコード（設定で JPEG 0.95 切替可） | クライアント内 WebAssembly AVIF エンコード（`.avif` 維持は「ファイル」へ保存、写真アプリ取り込み時は OS 仕様で JPEG 変換） |
| フォーカス・ズーム | `MediaStreamTrack.applyConstraints()` | 対応時は `applyConstraints()`、非対応時は Canvas/WebGL ズームで代替 |
| 画像保存フロー | `<a download>` による `.avif` 直接ダウンロード保存 | 撮影直後に Web Share API 共有シートを自動起動（`.avif` 維持は「“ファイル”に保存」／Safari「直接DL (.avif)」） |

## iPhone / Android での運用メモ（OS セキュリティ仕様について）

- **再読み込み時のカメラ許可を今後も継続する設定**
  - **iPhone (Safari / ホーム画面 PWA)**: OS 標準設定は「毎回確認」のため、iPhone の **「設定」→「アプリ」→「Safari」（iOS 17以前は「設定」→「Safari」）→「カメラ」→「許可」** を設定すると、通常ブラウザおよびホーム画面 PWA の再読み込みでも許可確認が出なくなります（通常 Safari のみの場合はアドレスバー左アイコン →「Webサイトの設定」→「カメラ」→「許可」でも設定可能）。
  - **Android (Chrome)**: 許可ダイアログで「今回のみ」ではなく **「サイトにアクセスするたびに許可」** を選択してください。
- **0.5× 超広角カメラが利用できる条件**
  - **iPhone (iOS 16.3+)**: カメラ許可後に背面カメラから「背面超広角カメラ」が検出され、`0.5×` ボタンが自動で表示されます（`0.5×` 未対応の単眼モデル等では非表示）。
  - **Android (Chrome)**: Chrome および端末カメラドライバが Web ページへ広角縮小（`zoom < 1.0`）または独立した背面超広角デバイスを公開している場合に `0.5×` が有効になります（※Google Pixel 系など Chrome が論理マルチカメラのズーム下限を `1.0` に固定している端末では OS/ブラウザ側の制限により表示されません。複数の背面デバイスを公開している機種は設定シート内の「背面レンズ手動切替」からも選択できます）。
- **iPhone で AVIF (.avif) をそのまま保存する方法（重要）**
  - Qcam はクライアント側で本物の `image/avif`（`Qcam_YYYYMMDD_HHMMSS.avif`）を生成していますが、iOS の「写真」アプリ（共有シートの **「画像を保存」** やプレビュー画像の **長押し「“写真”に保存」**）へ取り込むと、iOS（PhotoKit）の仕様により **自動で JPEG に変換してカメラロールに保存されます**。
  - **`.avif` 形式のまま無変換で保存したい場合**: 共有シートで **「“ファイル”に保存」** を選択するか、通常 Safari のプレビュー画面にある **「直接DL (.avif)」** をタップすると `ファイル` アプリへ `.avif` のまま保存できます。「写真」アプリへの直接保存を重視する場合は設定で `JPEG` も選べます。
